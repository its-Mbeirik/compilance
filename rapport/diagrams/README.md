# Diagrammes ConformIA — Instructions de rendu

## Fichiers

| Fichier | Contenu |
|---------|---------|
| `architecture.puml` | Architecture générale du système |
| `use_case.puml` | Diagramme des cas d'utilisation |
| `class_diagram.puml` | Diagramme de classes |
| `sequence.puml` | Diagramme de séquence (analyse d'un contrat) |

## Comment générer les images (PNG/SVG)

### Option 1 — En ligne (recommandé, sans installation)

1. Aller sur https://www.plantuml.com/plantuml/uml/
2. Copier-coller le contenu du fichier `.puml`
3. Cliquer sur **Submit**
4. Clic droit sur l'image → **Enregistrer l'image sous...**

### Option 2 — Extension VS Code

1. Installer l'extension **PlantUML** (jmlooper.plantuml)
2. Ouvrir le fichier `.puml`
3. `Alt + D` pour prévisualiser
4. Clic droit → **Export Current Diagram** → PNG

### Option 3 — Plugin IntelliJ / PyCharm

Installer le plugin **PlantUML integration** puis ouvrir le fichier.

## Résolution recommandée pour le rapport

Exporter en **PNG 300 DPI** ou **SVG** pour une qualité optimale dans le PDF.
